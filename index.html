CAPTURE AUTOMATION

One tap from Uber

iPhone Back Tap → screenshot → local text extraction → Radar. Offer capture and recognizable lifecycle screens use the same endpoint. No Uber credentials or network interception.

iPhone Shortcut setup

In Shortcuts: Take Screenshot → Extract Text from Image → Get Current Location → Get Contents of URL (POST to endpoint; JSON text = recognized text; optional lat/lng). Headers: Content-Type application/json and x-capture-token your private Radar token. Show Notification using verdict or state. Then Settings → Accessibility → Touch → Back Tap → Double Tap → Radar Capture. A screenshot of a pickup or dropoff screen can advance the lifecycle when the preceding step is already recorded.

Screenshots still require your tap. Full background capture requires a separate permissioned native iPhone app; this PWA cannot read Uber's screen or encrypted HTTPS messages.
